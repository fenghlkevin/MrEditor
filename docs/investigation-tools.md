# TextStack 排查工具

## 目录搜索与替换

从“编辑 → 目录搜索与替换”或 ⇧⌘F 打开。选择目录，填写搜索和替换文本，设置正则、大小写和扩展名（例如 `log,txt,json`），点击“搜索 / 预览替换”。正则替换支持 `$1` 等捕获组；普通文本替换将 `$1` 作为字面文本。

结果每行代表一处匹配，包含相对路径、源行号和替换前后文本。使用勾选框、全选、清空勾选选择修改范围，双击打开源文件。前后内容较长时显示前 160 字符；实际替换使用完整内容。

替换时先检查所有选中文件的原始字节，拒绝预览后发生变化或当前编辑器中已打开的文件，避免覆盖未保存编辑。全部已打开文件可直接在原有搜索栏选择对应范围并预览替换，保留编辑器撤销流程。

磁盘替换前在 `~/Library/Application Support/TextStack/ReplacementBackups/<本次 UUID>/` 写入原始字节和 `manifest.json`（备份文件名 → 原路径）。备份失败则不替换。文件分别原子保存，保留编码、BOM、换行与 POSIX 权限；跨文件操作不提供整体原子性。后续失败会报告已修改文件及备份目录。恢复时按清单将所需原文复制回源路径；磁盘替换不进入编辑器撤销历史。

目录扫描跳过隐藏文件、应用包和符号链接。单文件最多 32 MiB，最多保留 128 MiB 匹配文件原文、5000 个匹配项；最多遍历 100000 项。达到上限显示提示，已列出的勾选项仍可替换。更大的单文件仍使用现有大文件搜索。扫描支持取消，修改条件会使旧结果失效。权限错误与超大文件显示跳过提示。

## 日志时间轴、统计与字段筛选

从“格式 → 日志时间轴与字段筛选”打开。首次分析读取打开工具时的未保存编辑或文件数据，后续分析复用快照；源文档变化后重新打开工具。

时间桶可选分钟、小时、天，显示包含时间戳的匹配记录数、ERROR/FATAL 与 WARN 数量。双击时间桶或筛选行定位源文档。上方总行数、级别和识别字段为整个输入的统计，时间桶与下方结果应用筛选条件。下方最多显示 1000 行、每行 2000 字符；导出包含全部匹配行，保留原始换行和堆栈续行。

字段值精确匹配、区分大小写。规范化级别使用大写，WARNING 映射到 WARN；级别筛选例如 `level = ERROR`。字段名支持原始键及别名：`severity → level`、`trace_id → traceId`、`thread_name → thread`、`service.name → service`。普通文本识别 key=value、key:value、单/双引号值、常见级别和方括号线程。该启发式不能理解所有日志格式；未识别字段可先使用原有文本/正则搜索。

支持已有 ISO、Apache/nginx、Syslog、Unix 秒/毫秒解析器；JSON 日志从 timestamp、time、@timestamp、datetime 提取时间。自动检测前 1 MiB / 1000 行，可手动指定格式。无时区时间使用界面中的 UTC 偏移；Syslog 年份由界面指定并按顺序处理跨年。没有时间戳时字段筛选仍可用，时间范围筛选不纳入无日期独立记录。源文件不被导出覆盖。

按 UTF-8 行扫描，不构造全文字符串或全部记录数组；单行最多 4 MiB、时间桶最多 100000 个。非 UTF-8 输入转换限制为 64 MiB。取消或失败不保留部分结果。

## SSH 排查

- **重连 / 刷新**：重新探测能力并读取当前远程文件末尾，保留当前选中文件路径；原来正在跟随时恢复跟随。
- **自动重连**：勾选后，跟随中断分别等待 2、4、6 秒尝试恢复，最多三次；收到新日志后重置次数。关闭、断开、停止跟随或取消勾选会取消等待中的尝试。重新读取末尾可能与此前内容重叠，断线期间超过末尾读取范围的日志不会自动补齐。
- **轮转跟随**：服务器能力探测确认支持 `tail -F` 时按文件名继续跟随新文件；不支持时仍使用 `tail -f` 并显示能力提示。轮转模式新行不推算全局行号，避免误导。远程跟随最多保留最新 20000 行。
- **独立窗口**：把当前远程日志再打开到独立窗口，可在另一窗口选择不同文件或连接其他服务器并排查看。
- **分析已加载日志**：统计与筛选当前已加载的内容快照，窗口标题明确这一范围。该功能不扫描整个远程文件；全文关键词搜索继续使用已有服务器侧 grep。

所有连接继续使用现有主机指纹验证、跳板机与凭据管理，不修改用户 SSH 配置。

## 字符与编码

格式菜单打开检查器。存在选区时检查选区，否则检查当前内容快照；上限 64 MiB。可以切换 UTF-8、Shift-JIS、EUC-JP、UTF-16 LE/BE，检查无法在该编码中无损表示的字符。

统计 Unicode 标量数、UTF-8 大小和各类换行数。列出可疑零宽空格、BOM、不换行空格、双向文本控制和控制字符，以及不兼容字符的位置与码点；位置按 Unicode 标量计数，最多显示 1000 条，统计包含全部内容。选区检查的位置相对于选区。ZWJ 等字符也用于正常文字、表情，因此检查器只报告，不自动删除或转换。

## Markdown 导出

格式菜单打开独立导出预览，可切换浅色 / 深色。输入支持最多 8 MiB，内容使用打开工具时的快照。

- **HTML**：内嵌渲染 CSS、公式字体和文档目录内本地图片；包含已渲染 Mermaid SVG，无需联网或 JavaScript。CSP 禁止脚本和外部资源；本地图片单图最多 20 MiB、总计 64 MiB，缺失图片会报告错误。
- **PDF**：先渲染全文，再按 A4、36 点页边距生成矢量分页，尽量在段落/表格行/图表边界分页；超过一页的长代码块或大图仍可能被切分。不依赖系统打印机。
- **PNG**：从全文 PDF 渲染长图，避免只捕获可见区域；最多 16000 像素高、4000 像素宽。

PDF 全文渲染高度上限 100000 像素。不能覆盖原 Markdown 文件。普通内容图片仍遵循预览的目录边界；不会下载远程图片。
